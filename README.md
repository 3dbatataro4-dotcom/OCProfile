# OCProfile
非常重要的人物資料整理網站。 - Deployed by EZPage


雲端大型存檔修正（2026-10-21）：既有協作 v2 專案依序套用 `supabase/upgrade-collaboration-v2-performance.sql`、`supabase/upgrade-collaboration-v2-timeouts.sql`。後者僅為兩個整批提交函式設定 55 秒處理時間，不變更帳號權限或存檔格式。一般前端請求維持 30 秒，整批提交等待 75 秒；結果不明的網路中斷只會以相同批次識別碼確認一次，不會另建批次重複上傳。

`supabase/verify-large-save-rollback.sql` 可用來診斷大型分段提交；它以 session 暫存函式驗證現有資料的 20 筆測試變更，隨即回滾，並回報原版本、歷史、修改紀錄及分段資料是否維持不變。正式存檔不會寫入測試內容。


### 角色生日與星願召喚分組

角色建立精靈與角色編輯新增「生日（選填）」，只填月份與日期（支援 2 月 29 日），舊版含年份的生日也會改以月日顯示；未填寫時不顯示，填寫後會出現在角色卡與人物檔案中，並隨原有備份儲存。

星願召喚新增「隨機分組」，使用人物召喚卡池，可兩兩配對或自訂每組人數；每人只會出現一次，尾組不足人數仍完整保留。結果可下載 TXT、PNG，PNG 使用獨立分組卡片，標示組號、人數與完整成員；分頁保留完整組別，超大組別使用同組號續頁；分組結果與歷史會隨抽卡資料保存。

主題抽獎的「抽獎預設」可保存主題、所有獎項／名額／說明、額外名單、是否重複中獎與參加人物設定，支援套用、另存、更新與刪除，並隨備份保存。套用預設不會清除既有抽獎結果。

隨機配對／分組採用人物召喚風格，逐組揭曉結果，並可開關召喚音效；支援減少動態效果偏好。素材庫側邊拉條使用與全站一致的細金色樣式。

分組支援自訂標題（可在分組後重新命名），同步顯示於 TXT／PNG。設定簡化為雙人配對與多人配對；多人可自訂每組人數。PNG 雙人配對每排兩組、多人每排至多四位成員，優先使用單張長圖，超大名單才分頁。
