# Supabase 雲端同步設定

1. 在這個網站所使用的 Supabase 專案開啟 **SQL Editor**。
2. 將 `setup.sql` 全部貼入並執行。這份 SQL 可以重複執行；它會替換舊版同步函式，但不會清除既有雲端存檔。
3. 到 **Authentication → Users** 確認手機登入使用者存在，並使用同一組 Email／密碼登入網站的「雲端存檔」。
4. 重新部署網站後，在手機完整關閉並重開頁面，再嘗試只勾選「同人論壇」上傳。大型論壇會自動拆成小片段上傳，再由資料庫完整驗證後一次提交。

若手機或瀏覽器資料已被清除，重新登入同一個雲端帳號後，勾選要取回的區域並按「從雲端完整復原」。這會略過逐項合併，以雲端存檔恢復本機；操作前的本機版本仍會暫存為 `oc_cloud_before_workshop`／`oc_cloud_before_forum`。

同步資料以登入使用者 ID 隔離。瀏覽器內的 Supabase publishable key 是公開用戶端金鑰；資料保護依靠登入權杖、資料列安全性與 RPC 內的使用者檢查。
